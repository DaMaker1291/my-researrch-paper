1. Number Theory

What is the value of $\frac{2026^2 - 2020^2}{2026 + 2020}$?

A: $2$
B: $6$
C: $4046$
D: $2023$
E: $12$
Answer: B (6)

Using the difference of two squares identity, $a^2 - b^2 = (a-b)(a+b)$:

$$\frac{2026^2 - 2020^2}{2026 + 2020} = \frac{(2026 - 2020)(2026 + 2020)}{2026 + 2020} = 2026 - 2020 = 6$$

2. Geometry

In the diagram shown, $ABC$ is an isosceles right-angled triangle with $\angle ABC = 90^\circ$. Points $D$ and $E$ lie on $AC$ such that $BD = BE$ and $\angle DBE = 30^\circ$. What is the size of $\angle ABD$?

A: $15°$
B: $22.5°$
C: $30°$
D: $37.5°$
E: $45°$
Answer: C (30°)

Since $\triangle ABC$ is isosceles with $\angle B = 90°$, we have $\angle A = \angle C = 45°$. Since $BD = BE$ and $D, E$ are on $AC$, by symmetry about the altitude from $B$: $\angle ABD = \angle EBC = \frac{90° - 30°}{2} = 30°$.

3. Algebra

If $x + \frac{1}{x} = 4$, what is the value of $x^3 + \frac{1}{x^3}$?

A: $52$
B: $64$
C: $76$
D: $48$
E: $56$
Answer: A (52)

Cube both sides: $\left(x + \frac{1}{x}\right)^3 = x^3 + 3x \cdot \frac{1}{x}\left(x + \frac{1}{x}\right) + \frac{1}{x^3} = x^3 + 12 + \frac{1}{x^3}$

$64 = x^3 + \frac{1}{x^3} + 12 \implies x^3 + \frac{1}{x^3} = 52$

6. Number Theory

What is the remainder when $3^{2026}$ is divided by $5$?

A: $1$
B: $2$
C: $3$
D: $4$
E: $0$
Answer: D (4)

Powers of 3 mod 5 cycle with period 4: 3, 4, 2, 1. Since 2026 = 4×506 + 2, we get 3^2026 ≡ 3^2 ≡ 4 (mod 5).

7. Algebra / Functions

The function $f(x)$ satisfies $f(x) + 2f(1-x) = x^2$ for all real numbers $x$. What is the value of $f(2)$?

A: $-2$
B: $0$
C: $2$
D: $\frac{2}{3}$
E: $-\frac{2}{3}$
Answer: E ($-\frac{2}{3}$)

Sub x=2: f(2) + 2f(-1) = 4. Sub x=-1: f(-1) + 2f(2) = 1. Multiply second by 2: 2f(-1) + 4f(2) = 2. Subtract first: 3f(2) = -2, so f(2) = -2/3.

8. Geometry

In $\triangle ABC$, $D$ is the midpoint of $BC$ and $E$ is the midpoint of $AD$. The line $BE$ extended intersects $AC$ at $F$. What fraction of the area of $\triangle ABC$ is the area of $\triangle AEF$?

A: $\frac{1}{6}$
B: $\frac{1}{8}$
C: $\frac{1}{12}$
D: $\frac{1}{10}$
E: $\frac{1}{16}$
Answer: C ($\frac{1}{12}$)

By Menelaus' theorem on triangle ABD with transversal C-F-E: BE:EF = 3:1. Since AF = AC/3 and E divides BF in ratio 3:1, Area(AEF) = (1/4)(1/3) = 1/12 of Area(ABC).

9. Logic / Sequences

A sequence $a_1, a_2, a_3, \dots$ satisfies $a_1 = 2$ and $a_{n+1} = \frac{a_n - 1}{a_n + 1}$ for all $n \ge 1$. What is $a_{2026}$?

A: $2$
B: $\frac{1}{3}$
C: $-\frac{1}{2}$
D: $-3$
E: $1$
Answer: B ($\frac{1}{3}$)

Period 4: a₁=2, a₂=1/3, a₃=-1/2, a₄=-3, a₅=2. Since 2026 = 4×506 + 2, a₂₀₂₆ = a₂ = 1/3.

10. Algebra

How many real solutions $(x, y)$ satisfy the simultaneous equations $x + y = 6$ and $x^2 y^2 - 10xy + 9 = 0$?

A: $0$
B: $2$
C: $3$
D: $4$
E: $1$
Answer: C (3)

Factor: (xy-9)(xy-1)=0. Case xy=9 with x+y=6 gives (3,3). Case xy=1 with x+y=6 gives t²-6t+1=0, two real roots. Total = 1 + 2 = 3.

13. Number Theory

How many positive integers $n$ have the property that $n+3$ divides $n^2 + 11$?

A: $2$
B: $3$
C: $4$
D: $5$
E: $6$
Answer: C (4)

n²+11 = (n-3)(n+3)+20. Need n+3|20 with n≥1, so n+3∈{4,5,10,20} → n∈{1,2,7,17}. Four values.
